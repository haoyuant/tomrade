# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability** ([direct link](https://github.com/haoyuant/tomrade/security/advisories/new)). Only the maintainer sees the report, and the fix is discussed in that private advisory.

Include what you can: the Tomrade version (Settings › About), your system, the steps to reproduce, and what an attacker gains. A proof of concept helps.

Once a fix ships, the advisory is published and credits you, unless you'd rather not be named.

## Supported versions

Tomrade is in preview. Fixes go into the latest release only; an installed copy offers the update when it is out.

## Scope

This repository and the desktop app built from it. For the official plugins, report on [tomrade-plugins](https://github.com/haoyuant/tomrade-plugins) the same way. A bug in a dependency belongs upstream, unless the way Tomrade uses it makes things worse.
