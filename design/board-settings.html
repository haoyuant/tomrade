Sprint 12 / Board settings

Board

A board is a saved view over this project's issues — a filter, a grouping and a column set. Issues are never copied into it, so the same issue can appear on any number of boards.

Start from a template

Grouping

What each column represents. Dragging a card between columns writes that field on the issue; the manual order is stored per board.

Columns

Reorder to change the board. Switch a column off to hide it — its issues stay in the project and keep their status.

Filter

Narrows which issues reach the board. An empty filter shows everything in the project.
