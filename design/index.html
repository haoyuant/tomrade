Tomrade Next / Prototype

Issue tracking workbench · desktop prototype

A backlog that reads like a printed ledger.

Linear's real lesson is speed and density, not dark cool-grey. Tomrade is local-first, single-user and keeps an append-only oplog where every agent write carries provenance — a personal engineering notebook a coding agent is also allowed to write in. So the interface is set as one: warm paper, ink-blue accent, serif carrying hierarchy, marginalia instead of badges.

Five moves

Everything else is restraint.

01

Rules, not boxes

Depth is hairlines and whitespace. The only shadow is a whisper on hover — no transform, no glow.

02

Columns as chapters

Column heads are numbered like sections: the number in ink-blue, the label in near-black. No six competing hues.

03

Provenance as marginalia

Agent-written issues get a short tick in the card's gutter. Human work shows nothing — the default state is silence.

04

A transcript, not bubbles

The assistant is set as correspondence: user turns compact and flush right, replies as full-measure body text.

05

One type pairing

Charter at weight 500 for everything with a voice; mono with tabular figures for everything countable.
