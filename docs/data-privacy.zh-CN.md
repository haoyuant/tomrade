# 数据使用与隐私说明

[English](data-privacy.md)

Tomrade 使用功能使用统计，了解哪些功能有用、使用了多少次、花了多少有效时间。
本文只说明这项统计功能。账号登录、项目同步、AI 服务商，以及你主动发送的故障
报告，是各自独立的数据流程。

## 统计包含什么

- 使用的功能，例如看板或笔记，以及打开、创建等预先定义的动作，不含对象的具体内容。
- 计时功能的有效使用时长、动作次数和事件时间。不计后台时间；连续 60 秒没有输入后暂停计时。
- 随机匿名标识，用于统计活跃安装和再次使用情况。这些数量不代表可识别的具体人数。
- 应用版本、操作系统类别（macOS、Windows 或 Linux）、事件格式和功能清单的版本。
  事件还包含随机事件/会话编号和顺序信息，用来处理重试。
- 中国大陆、亚太、欧洲、北美或其他这五类粗粒度地区之一。动作可以带预先定义的
  类别，例如引擎或渠道类型，不包含用户输入的文字。

**使用统计不采集具体项目数据：** 不含项目名称、工单标题或正文、笔记、聊天内容、
提示词、模型回复、代码、文件名、仓库路径、搜索词或设置值；也不含邮箱、账号 ID、
硬件指纹或 IP 明文。客户端和接收端只允许预先定义的事件字段，出现额外内容字段
会拒绝整批数据。

网络服务为了接收请求，必然会接触来源地址。统计数据库只保存粗粒度地区，不保存
该地址或推导地区时用到的国家。托管与路由服务的日志也必须配置为不记录这些地址；
数据库表结构本身不能控制服务商日志。

## 匿名标识如何工作

Tomrade 在你的电脑上生成随机密钥。密钥留在本机，由它派生的标识随使用事件发送。
标识不来自账号、邮箱或硬件，不与账号或项目记录关联，不能用于登录，也不能解码
还原成账号身份。

标识每 365 天（约 12 个月）变化一次。你也可以在**设置 → 数据与隐私**中选择
**重置匿名标识**：生成新密钥与新标识，并丢弃尚未发送的事件。同一标识有效期间
的事件可以归在一起，这正是统计活跃和再次使用的方法。系统不提供新旧标识之间
的身份映射。这是在说明保护措施，不保证与任何外部信息组合后都绝无风险。

## 用途与保留期限

统计只用于产品分析：功能使用、有效时长、粗粒度地区与变化趋势。不用于广告、
个人画像或模型训练，也不出售给第三方。

| 数据 | 保留期限 |
| --- | --- |
| 本机尚未发送的事件 | 最多 7 天，同时受 20,000 条 / 20 MB 上限约束；先丢弃最旧事件 |
| 云端事件明细 | 180 天窗口；某个自然月内所有事件都超过 180 天后，按整月清理，因此部分事件会保留到该月清理时 |
| 含匿名标识的每日活跃记录 | 180 天 |
| 不含匿名标识的功能/动作汇总 | 25 个月 |

云端期限依赖定时清理任务实际运行。部署规范还要求备份最多保留 35 天、不含地址
的边缘状态码计数最多保留 30 天，这两项需要在托管服务中配置。
[运维说明](analytics.md)介绍了数据库任务和地区配置。仅有仓库代码不代表线上
服务已经部署，也不代表托管配置已经核验。

## 如何关闭

打开**设置 → 数据与隐私 → 匿名使用统计**并关闭开关。采集和计时会停止，进行中
的请求与重试会被取消，本机待发队列会清空，本地身份密钥会删除。关闭期间不会
发起新的使用统计请求，不影响项目工作、同步、许可证或更新。重新开启会生成
新的匿名标识。

关闭统计或重置标识，不会撤回服务端已经接收的事件；这些事件会按保留规则到期
清理。如果希望提前申请删除，请在重置或关闭**之前**复制设置中显示的标识，通过
私密支持渠道联系维护者，不要把它发到公开工单。请求只能依据该标识，不能依据
统计系统没有保存的邮箱或账号。规范要求在 30 天内处理这类请求；目前没有自助
删除按钮。已不含标识的汇总数据无法再对应到某个请求。

当前实现默认开启。中国大陆版本发布前，运营方必须解决规范中待确认的同意方式
和默认开关问题，并在首次上报前告知。本文不对部署作合规认证，也不替代该发布决定。

## 数据存放在哪里

设计采用中国大陆与国际两个独立端点。按双区配置部署后，中国大陆的明细留在
境内数据库，国际明细留在境外数据库。接收端拒绝地区不匹配的请求，客户端不会
把同一批数据跨区重试。共用的内部看板只读取两边的数字汇总，不在两边传输事件
明细或匿名标识。跨部署计数直接相加，不匹配标识。

只有地区路由、数据库地区限制、清理任务和服务商日志配置全部落实，才能对某个
发行版本承诺这项隔离。自行部署时请按[运维说明](analytics.md)检查端点；选择
“auto”本身不会创建境内外托管服务。
