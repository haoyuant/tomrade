# @tomradex/plugin-host

The Tomrade that `tomrade-plugin test` loads a plugin into: a throwaway project
with three sample issues, every contribution the plugin makes run once, then the
plugin's own scenario. It is installed with `@tomradex/plugin-cli`; nothing else
needs it.

Unlike the plugin SDK and CLI (Apache-2.0), this package is Tomrade's own code
and carries the repository's license, the Business Source License 1.1 — see
`LICENSE`. Testing plugins with it is a permitted use.
