## en
- Removing a worktree now also deletes its branch, here and on the remote, once everything on it has landed in the default branch. Two switches in Settings → Worktrees turn either one off.
- In the Start dialog you can set, for that ticket alone, whether its delivery is reviewed by an agent and whether the findings go back to its agent by themselves.
- A merged ticket whose branch Tomrade never saw now shows the changes its merge brought in.
- The settings pane for agents from the ACP registry is now called "ACP".
- Anonymous usage statistics now cover recently added features and the actions that were listed but never sent. Still no content of any kind; Settings → Data & privacy turns them off.

## zh
- 移除 worktree 时，如果分支上的提交都已进入默认分支，会一并删除本地和远端的分支。设置 → Worktree 里有两个开关，可以分别关掉。
- 开始工单时可以单独设定：交付后是否由 Agent 自动审查，审查意见是否自动交回给它的 Agent。
- 已合并的工单即使 Tomrade 没见过它的分支，现在也能看到这次合并带来的改动。
- ACP 注册表智能体的设置页改名为“ACP”。
- 匿名使用统计补上了近期的新功能，以及此前登记了却没有上报的操作。仍然不含任何内容，可以在 设置 → 数据与隐私 里关闭。
