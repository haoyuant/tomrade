## en
- Worktrees made outside the Hub (by an agent in your own terminal, or by you) are now listed with the rest, in Settings → Worktrees and under each repository, with what they take on disk. Remove takes one whose tickets are finished.
- A worktree folder git no longer knows (its repository was moved or deleted) is shown as left behind and can be removed by hand.
- After a pull request merges, your checkout's default branch is brought up to date by itself. Turn it off per repository in Project settings → Repositories.
- An update now says what changed, in the update notice and in Settings → About.

## zh
- Hub 之外的 worktree（终端里的智能体建的，或你自己建的）现在和其他 worktree 列在一起：设置 → Worktree 和每个仓库下都能看到占用，工单结束后可以直接移除。
- git 已经不认的 worktree 文件夹（原仓库被移动或删除）会标为“残留”，可以手动移除。
- PR 合并后，仓库目录里的默认分支会自动更新到最新。可在 项目设置 → 代码仓库 里按仓库关闭。
- 有新版本时会显示更新内容，在更新提示和 设置 → 关于 里都能看到。
